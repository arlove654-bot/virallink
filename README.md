# Virallink starter

A mobile-first React + Vite landing page using the agreed premium black and purple neon visual style.

## Run locally

1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Current functionality

- No customer login.
- Two decorative featured-image placeholders.
- ৳99 price.
- bKash / Nagad method selection.
- Shared payment number `01968642814`.
- Copy payment number.
- Transaction ID input.

## Important before publishing

This is a front-end starter only. The submit button currently displays a demo notice; it does **not** send or verify payments. Before accepting real payments, connect a secure backend and a supported payment-verification workflow. Do not treat a typed Transaction ID as proof of payment. Telegram notifications/approval can be added in a later backend step. Never put bot tokens or secret API keys in frontend code.

Replace the two abstract visual placeholders with images you own or are licensed to use.
